## 二、已执行的修订

### 修订 1：E5 控制模拟（对应意见 1）

- 候选动作改为只由决策时可观测量生成：`anchor = mean UF delivered so far`（T 时刻已知），候选 `{1.0,0.9,0.8,0.7,0.6} × anchor`。

- 明确模型性质：`P(IDH | state, plan)` 是**条件风险模型**，不是识别出的反事实模型。
- 新增重叠诊断：候选与临床实际方案平均偏离 **0.174 L/h**（约为观测均值方案的 43%）；89% 候选落在观测支撑内，但支撑区间宽，故不足以证明可信。

### 修订 2：概率校准（对应意见 2）

- 新增 **E8**：诊断 + Platt 重校准。
- 根因：`scale_pos_weight` / `pos_weight = 17:1` 改变了有效先验，且从未映射回真实发生率。
- 结果：Brier **0.116–0.175 → 0.0515–0.0525**（全部低于无技巧 0.0552）；AUPRC 不变（单调变换）。

### 修订 3：不确定性（对应意见 4）

- 新增 **E9**：按患者的 bootstrap（B=1,000）。
- AUPRC 95% CI：XGBoost 0.118–0.221；1D-CNN+MLP 0.117–0.268；Transformer 0.131–0.282。
